Installation Process

📦

System Prerequisites

Ensure your system is ready for Python 3.10+ development and PDF generation.

Install 'uv' Manager

curl -LsSf https://astral.sh/uv/install.sh | sh

PDF Engine

sudo apt install wkhtmltopdf
⬇️

Clone & Sync

Get the source code and let 'uv' manage the Python environment and dependencies (pdfkit, pywebview, etc).

git clone https://github.com/your-username/mnemo.git
cd mnemo
uv sync  # Creates venv & installs deps from uv.lock
⚡

Download Static Assets

Mnemo is designed to run offline. The provided shell script fetches Tailwind, CodeMirror, and KaTeX from CDNs to the local folder.

Script Action: download_front_libs.sh

  • Creates frontend/libs folder
  • Downloads tailwind.min.js, prism.js, etc.
  • Downloads & Unzips the KaTeX release
chmod +x scripts/download_front_libs.sh
./scripts/download_front_libs.sh
🚀

Run the Application

Launch the editor. Use 'uv run' to ensure the correct virtual environment context is used.

uv run mnemo
Tip: If PDF export fails, verify that wkhtmltopdf is in your system PATH.
